GeocarbPrecalibration.PriorSpec — Type
PriorSpec

One row of a GEOCARB_input_summaries_calib_*.csv file.

fieldmeaning
nameparameter or forcing name
kind:constant or :time_array
distribution:gaussian, :lognormal or :uniform
mean, two_sigmalocation and spread. For :gaussian, σ = two_sigma/2. For :lognormal, meanlog = log(mean) and sdlog = log(two_sigma/2), so two_sigma is a multiplicative factor (lhs_sampling.R:58).
lower, uppertruncation bounds (±Inf allowed; _inf in the file means -Inf)
calibratecalib == 1: sampled; otherwise fixed at mean
resamplethe resample column, kept for completeness

GeocarbPrecalibration.mean_time_forcings — Method
mean_time_forcings(series::AbstractArray{<:Real,3}, age) -> TimeForcings

Mean forcings from an n_time × n_samples × 12 array (forcings in TIME_FORCING_NAMES order), for example the accepted series of a previous experiment. This is what the two-stage Cretaceous experiment uses as new centres (the R version, par_time_mean_cret.csv, is affected by finding F-27).

source
GeocarbPrecalibration.read_time_arrays — Method
read_time_arrays(path; use_godderis = true) -> TimeArrayPrior{Float64}

Read a GEOCARB_input_arrays_*.csv file: an age column and, for each forcing X, a centre column X and a standard-deviation column eX. This reproduces parameterSetup.R:34-85:

  1. with use_godderis = true (the R default l_Godderis <- TRUE), fA, fAw_fA, fD, GEOG and their errors are taken from the *_Godderis columns (Goddéris et al. 2012);
  2. the centre of fAw_fA is divided by its present-day value (Krause et al. 2018); its standard deviation is not rescaled, as in the R code.

The file must list ages from oldest to youngest.

proxy_step_index(d::ProxyData, age::AbstractVector) -> Vector{Union{Int,Nothing}}

Model time step that each observation is compared against: the step whose age a satisfies a - dt/2 ≤ obs_age < a + dt/2 (getData.R:28-35), or nothing if none.

source
GeocarbPrecalibration.read_proxy_data — Method
read_proxy_data(path; proxies = (:paleosols, :alkenones, :stomata, :boron, :liverworts)) -> ProxyData

Read a CO2 proxy CSV (columns age, co2, co2_low, co2_high, proxy_type, reference; other columns are ignored) and keep the listed proxy types. As in getData.R:12-20, rows are grouped by proxy type in the order of proxies.

Temperature data

GeocarbPrecalibration.TemperatureData — Type
TemperatureData

Global temperature reconstruction of Mills et al. (2019, Gondwana Research): time in Ma (≤ 0, i.e. negative ages), CO2 bounds (ppmv) and temperature maximum, minimum and average (°C).

source
GeocarbPrecalibration.read_park_royer_2011 — Method
read_park_royer_2011(path) -> NamedTuple

Read ParkRoyer2011_Fig3_85varred.csv (Park & Royer 2011, Fig. 3: distribution of ΔT2x). Returns (deltaT2X, pdf, cdf). The file has CR-only line endings and a byte-order mark, both handled by read_csv_table.

source
GeocarbPrecalibration.read_temperature_data — Method
read_temperature_data(path) -> TemperatureData

Read Mills_GR_2019_temp_co2.csv. As in constraints.R:52, the six columns are taken by position: time, CO2 max, CO2 min, T max, T min, T average. Empty cells become NaN.
