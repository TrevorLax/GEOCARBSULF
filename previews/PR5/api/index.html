GeocarbPrecalibration.GeocarbPrecalibration — Module
GeocarbPrecalibration

Julia implementation of the GEOCARBSULFvolc long-term carbon-cycle model (Berner 2004, 2006a/b, 2008; Royer et al. 2014) and of the Latin-hypercube precalibration workflow of Wong et al. (2021), ported from the R/Fortran code in GEOCARB-precalibration.

The package is organised in layers that only depend on the layers above them:

  1. parameters/: named parameter, forcing and option types
  2. model/: the model itself (run_geocarb, run_geocarb!)
  3. io/: readers for the input CSV files and writers for results
  4. priors/, sampling/: prior distributions, Latin hypercube and time-series samplers
  5. constraints/: precalibration windows and the "percent outbound" metric
  6. precalibration/: experiment configuration, acceptance rules and the chunked, threaded, deterministic sampling engine (run_precalibration)
  7. analysis/: summaries used in the manuscript (quantiles, KDEs, correlations, ...)

Plotting lives in the GeocarbMakieExt package extension and is only loaded together with a Makie backend (for example using CairoMakie).

GeocarbPrecalibration.AcceptanceRule — Type
AcceptanceRule

Decides whether a simulation passes the precalibration. Rules are small values that can be combined; adding an experiment does not need new engine code.

  • OutboundRule: % outbound of CO2 or temperature ≤ threshold;
  • CretaceousWindowRule: temperature inside its window at one age;
  • AllOf: all of several rules.

Use accepts to evaluate a rule.

GeocarbPrecalibration.ConstantDesign — Type
ConstantDesign

How the constant parameters are spread over the unit hypercube.

  • ChunkedLHS (default): an independent Latin hypercube for every chunk of samples. Memory is bounded and each chunk is stratified (improvements doc §3.3).
  • GlobalLHS: one Latin hypercube over all n_sample points, sliced into chunks, as in lhs_sampling.R:33. Memory grows as 8·n_sample·n_params bytes (about 9 GB for 20 million × 56; finding F-11).

GeocarbPrecalibration.ConstantParams — Type
ConstantParams{T<:Real}

The 56 time-invariant parameters of GEOCARBSULFvolc. Field order matches the original Fortran Matrix_56; see CONSTANT_PARAMETER_NAMES. The meaning and units of each field are available with parameter_description and parameter_units.

Construct by name, never by position:

julia> update(p; deltaT2X = 4.0).deltaT2X

GeocarbPrecalibration.StepStatus — Type
StepStatus

Outcome of one model time step.

  • Converged: the CO2 solve converged and all checks passed.
  • NotConverged: the CO2 solve reached iteration_threshold (Fortran failed_run).
  • NaNEncountered: a NaN appeared inside the CO2 solve (Fortran ISNAN check).
  • RCO2OutOfRange: RCO2 left rco2_bounds (f90:524).
  • PresentDayCheckFailed: the present-day O2/CO2 check at t = 0 failed (f90:561).
  • InvalidState: RCO2 is NaN although the Fortran raised no failure flag. Outputs are then NaN rather than Inf, exactly as in the Fortran.

For the first four failure codes, co2 and o2 are +Inf at that step and temp is left as computed (the Fortran convention, finding F-08).

GeocarbPrecalibration.TimeSeriesSampler — Type
TimeSeriesSampler

Samplers of the 12 forcing time series around their centres. Both implementations apply the normalisation of lhs_sampling.R:106-112: fR, fL, fA, fAw_fA, fC are divided by their present-day value and GEOG has its present-day value subtracted.

  • InverseWishartSampler: the R algorithm. Draw Σ ~ IW(ν, (ν−p−1)·diag(σ²)) (mean diag(σ²)), then x ~ N(μ, Σ). Cost O(p³) per forcing.
  • MultivariateTSampler: the exact marginal of the above, a multivariate t, drawn in O(p) (improvements doc §3.2). Identical in distribution; it cannot return the covariance draws.

GeocarbPrecalibration.gcm_factor — Method
gcm_factor(t, p, o, k) -> GCM

Climate-sensitivity factor GCM ("capital gamma" in Berner 2004), with deltaT2X = GCM·ln 2:

  • in glacial intervals: GCM = GLAC·deltaT2X / ln 2;
  • otherwise, if o.dT2X_ramp and t ∈ (end, start] of o.dT2X_ramp_interval, the supplemental ramp: fac = (GLAC·(start − t) + (t − end)) / (start − end), GCM = fac·deltaT2X / ln 2 (run_geocarb_supp.f90:324-336);
  • otherwise GCM = deltaT2X / ln 2.

k are the ResolvedConstants (they carry ln 2, possibly rounded to single precision as in the Fortran).

GeocarbPrecalibration.legacy_percent_outbound — Method
legacy_percent_outbound(series, w::Windows) -> Float64

Fraction of time steps at which series lies outside the window, with the exact semantics of percent_outbound.R (Mills et al. 2019):

  • if any value is ±Inf (a failed Fortran step), return 1.0;
  • otherwise, if any value is NaN, return NaN (R returns NA; a run with NaN never satisfies ≤ threshold);
  • otherwise count(x < low | x > high) / n.

GeocarbPrecalibration.run_geocarb — Method
run_geocarb(p::ConstantParams, f::TimeForcings; options = ModelOptions()) -> GeocarbResult

Run GEOCARBSULFvolc from 570 Ma to the present on the age grid of f.

This is a line-by-line port of fortran/src/run_geocarb.f90 (and, through ModelOptions, of run_geocarb_supp.f90). The model never throws because of the parameter values: numerical failures are reported per step in result.status (see StepStatus) with the Fortran output conventions (co2 = o2 = Inf on failed steps). Invalid inputs (for example an age grid whose spacing is not options.dt) raise an ArgumentError before the run starts.

Examples

julia> table = read_prior_table(datapath("GEOCARB_input_summaries_calib_all.csv"));

julia> p = mean_constants(table);

julia> f = read_time_arrays(datapath("GEOCARB_input_arrays_NewDegassing.csv")).center;

julia> r = run_geocarb(p, f);

julia> succeeded(r)
true

julia> length(r.co2)   # ppmv, 58 values from 570 Ma to the present
58

julia> round.(r.co2[1:3]; sigdigits = 6)
3-element Vector{Float64}:
 5473.6
 5663.08
 6226.25

julia> round(r.co2[end]; digits = 1)   # present day
243.7

GeocarbPrecalibration.run_precalibration — Method
run_precalibration(cfg::ExperimentConfig; max_parallel = Threads.nthreads(),
                   checkpoint_dir = nothing, verbose = true) -> PrecalibrationResult

Run one precalibration experiment:

  1. read the priors, forcing arrays, proxy data and temperature data;
  2. in chunks of cfg.n_per_chunk, sample constants (Latin hypercube through the truncated priors) and forcing series, run the model, and keep the samples that pass the acceptance rule;
  3. stop once cfg.n_accept_min samples are accepted (keeping exactly that many) or after cfg.n_sample simulations.

Chunks are independent: chunk c uses its own StableRNG seeded from (cfg.seed, c). Up to max_parallel chunks run at the same time on separate threads, and their results are consumed in chunk order, so the result does not depend on the number of threads. With checkpoint_dir, every finished chunk is written there and reused if the run is restarted.

GeocarbPrecalibration.solve_rco2 — Method
solve_rco2(t, rco2, fwsi_nc, gcm, RT, GEOG, p, o, k) -> (rco2, status, iterations)

Damped Newton solve for RCO2 (CO2 relative to 250 ppmv) at age t, starting from the previous step's value. Returns the new RCO2, a StepStatus (Converged, NotConverged or NaNEncountered) and the number of iterations.
