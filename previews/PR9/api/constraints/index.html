Constraints and precalibration API

CO2 and temperature windows, % outbound, acceptance rules, experiment configurations, and the precalibration engine and its results.

Windows

GeocarbPrecalibration.Windows — Type
Windows

Lower and upper bounds of a precalibration window at every model time step.

source
GeocarbPrecalibration.co2_windows — Method
co2_windows(proxy::ProxyData, age; nsig = 1.0, bounds = (0.0, 50_000.0)) -> Windows

CO2 windows (constraints.R:28-43). For each model step, the proxies within ±dt/2 of its age are pooled. Each proxy spans log10(co2) ± nsig·log10(co2_high/co2), and the window is the envelope of those spans, intersected with bounds. Steps without data get the full bounds.

source
GeocarbPrecalibration.shift — Method
shift(w::Windows, delta::AbstractVector) -> Windows

Window moved by delta at every step (for example to add the solar term back in for plotting; constraints.R:72-73 did this with the fixed prior mean of Ws, finding F-19).

source
GeocarbPrecalibration.temperature_windows — Method
temperature_windows(data::TemperatureData, age; nsig = 1.0) -> Windows

Temperature windows from Mills et al. (2019) (constraints.R:51-71): [T_avg − nsig·(T_avg − T_min), T_avg + nsig·(T_max − T_avg)] at the record whose time equals −age. The windows include the solar-luminosity effect and are compared with temp + 15 from the model (see temperature).

Percent outbound

GeocarbPrecalibration.legacy_percent_outbound — Method
legacy_percent_outbound(series, w::Windows) -> Float64

Fraction of time steps at which series lies outside the window, with the exact semantics of percent_outbound.R (Mills et al. 2019):

  • if any value is ±Inf (a failed Fortran step), return 1.0;
  • otherwise, if any value is NaN, return NaN (R returns NA; a run with NaN never satisfies ≤ threshold);
  • otherwise count(x < low | x > high) / n.

Because the Fortran never sets temperatures to Inf, a temperature series of a failed run can still score below the threshold (finding F-04). Use percent_outbound with reject_failed = true to avoid that.

source
GeocarbPrecalibration.percent_outbound — Method
percent_outbound(r::GeocarbResult, w::Windows, variable; T0 = 15.0, reject_failed = false) -> Float64

% outbound of a model run for variable = :co2 (compared as is) or :temp (compared as r.temp .+ T0, see temperature). With reject_failed = true, any run with a failed step scores 1.0, whatever the variable. With false (the default), the result equals legacy_percent_outbound.

Acceptance rules

GeocarbPrecalibration.AcceptanceRule — Type
AcceptanceRule

Decides whether a simulation passes the precalibration. Rules are small values that can be combined; adding an experiment does not need new engine code.

  • OutboundRule: % outbound of CO2 or temperature ≤ threshold;
  • CretaceousWindowRule: temperature inside its window at one age;
  • AllOf: all of several rules.

Use accepts to evaluate a rule.

source
GeocarbPrecalibration.AllOf — Type
AllOf(rules...)

Accept if every rule accepts.

source
GeocarbPrecalibration.CretaceousWindowRule — Type
CretaceousWindowRule(age)

Accept only if temp + T0 lies inside the temperature window at age (Myr ago); see lhs_sampling_cret.R:136-140. A NaN temperature fails. The R code used the step index 49, which is 90 Ma on the 570:−10:0 grid (finding F-03).

GeocarbPrecalibration.OutboundRule — Type
OutboundRule(variable, threshold; reject_failed = false)

Accept if the % outbound of variable (:co2 or :temp) is ≤ threshold (lhs_sampling.R:150-163). A NaN score never passes. With reject_failed = true, runs with any failed step score 1 (finding F-04).

GeocarbPrecalibration.load_experiments — Method
load_experiments(path) -> Vector{ExperimentConfig}

Read an experiment TOML file. Without a [grid] table it describes one experiment. With a [grid] table, one experiment is created for every combination of grid.constraint (outer loop) and grid.threshold (inner loop), in that order, as expand.grid did in lhs_driver.R. Seeds are then

  • seed_multiplier * index with index = 1, 2, … (the R rule 1234*idx_experiment), or
  • one experiment per entry of grid.seeds, or
  • the top-level seed.

Relative data-file names are resolved against data_dir (default: the package's data/ directory). output_dir and time_center_from are relative to the current working directory.

Running a precalibration

GeocarbPrecalibration.prepare_precalibration — Method
prepare_precalibration(cfg::ExperimentConfig) -> PrecalibrationSetup

Read all inputs and build the priors, samplers, windows and acceptance rule of an experiment. Called by run_precalibration; exposed for inspection and tests.

source
GeocarbPrecalibration.run_precalibration — Method
run_precalibration(cfg::ExperimentConfig; max_parallel = Threads.nthreads(),
                   checkpoint_dir = nothing, verbose = true) -> PrecalibrationResult

Run one precalibration experiment:

  1. read the priors, forcing arrays, proxy data and temperature data;
  2. in chunks of cfg.n_per_chunk, sample constants (Latin hypercube through the truncated priors) and forcing series, run the model, and keep the samples that pass the acceptance rule;
  3. stop once cfg.n_accept_min samples are accepted (keeping exactly that many) or after cfg.n_sample simulations.

Chunks are independent: chunk c uses its own StableRNG seeded from (cfg.seed, c). Up to max_parallel chunks run at the same time on separate threads, and their results are consumed in chunk order, so the result does not depend on the number of threads. With checkpoint_dir, every finished chunk is written there and reused if the run is restarted.
