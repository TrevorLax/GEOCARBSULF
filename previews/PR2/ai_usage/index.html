Verification

AI-assisted code is held to the same checks as any other code. Continuous integration runs all of them on every push and pull request:

  1. Live comparison with the original code (test/legacy_comparison/). The unmodified R/Fortran code is run on 1000 prior samples and six supplemental variants. Julia must reproduce CO2, O2 and temperature at every step within rtol = 1e-8, or 1e-4 after a run's first failed step. The positions of failed steps must be identical, and % outbound must be equal.
  2. Golden-master fixtures from the compiled Fortran (test/regression/), checked on Linux, macOS and Windows.
  3. Unit, statistical, workflow and quality tests (Aqua.jl), and doctests of every documented example.

Responsibility

The authors have reviewed all AI-assisted code, documentation and text, understand it, and take full responsibility for its correctness and for the content of the paper. No AI tool is listed as an author.

Contributions

Contributors must say in their pull request whether and how AI tools were used (see CONTRIBUTING.md). The pull-request template asks for it. Significant AI-assisted changes are noted in CHANGELOG.md.
