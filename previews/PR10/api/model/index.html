Model API

Running the GEOCARBSULFvolc model and its building blocks, in the order of a time step.

Running the model

GeocarbPrecalibration.run_geocarb! — Method
run_geocarb!(out::GeocarbResult, p, f; options = ModelOptions()) -> out

In-place version of run_geocarb: overwrite the pre-allocated out (see GeocarbResult{T}(age)). It does not allocate, which matters inside the sampling loop.

source
GeocarbPrecalibration.run_geocarb — Method
run_geocarb(p::ConstantParams, f::TimeForcings; options = ModelOptions()) -> GeocarbResult

Run GEOCARBSULFvolc from 570 Ma to the present on the age grid of f.

This is a line-by-line port of fortran/src/run_geocarb.f90 (and, through ModelOptions, of run_geocarb_supp.f90). The model never throws because of the parameter values: numerical failures are reported per step in result.status (see StepStatus) with the Fortran output conventions (co2 = o2 = Inf on failed steps). Invalid inputs (for example an age grid whose spacing is not options.dt) raise an ArgumentError before the run starts.

Examples

julia> table = read_prior_table(datapath("GEOCARB_input_summaries_calib_all.csv"));

julia> p = mean_constants(table);

julia> f = read_time_arrays(datapath("GEOCARB_input_arrays_NewDegassing.csv")).center;

julia> r = run_geocarb(p, f);

julia> succeeded(r)
true

julia> length(r.co2)   # ppmv, 58 values from 570 Ma to the present
58

julia> round.(r.co2[1:3]; sigdigits = 6)
3-element Vector{Float64}:
 5473.6
 5663.08
 6226.25

julia> round(r.co2[end]; digits = 1)   # present day
243.7

GeocarbPrecalibration.StepStatus — Type
StepStatus

Outcome of one model time step.

  • Converged: the CO2 solve converged and all checks passed.
  • NotConverged: the CO2 solve reached iteration_threshold (Fortran failed_run).
  • NaNEncountered: a NaN appeared inside the CO2 solve (Fortran ISNAN check).
  • RCO2OutOfRange: RCO2 left rco2_bounds (f90:524).
  • PresentDayCheckFailed: the present-day O2/CO2 check at t = 0 failed (f90:561).
  • InvalidState: RCO2 is NaN although the Fortran raised no failure flag. Outputs are then NaN rather than Inf, exactly as in the Fortran.

For the first four failure codes, co2 and o2 are +Inf at that step and temp is left as computed (the Fortran convention, finding F-08).

source

GeocarbPrecalibration.temperature — Method
temperature(r::GeocarbResult; T0 = 15.0, geog = nothing, Ws = nothing) -> Vector

Global mean surface temperature implied by a model run, with the conventions of the original code made explicit (finding F-20):

  • r.temp is GCM·ln(RCO2) − Ws·t/570: warming from CO2, minus the solar term.
  • temperature(r) adds the present-day temperature T0 (15 °C, Berner 2004). This is the quantity compared with the Mills et al. (2019) windows during precalibration (lhs_sampling.R:137).
  • temperature(r; geog = f.GEOG) also adds the palaeogeography term. This is what the R analysis scripts plot as hindcasts (analysis_and_plots.R:140).
  • temperature(r; Ws = p.Ws) adds the solar-luminosity term back in.

Reservoir state

GeocarbPrecalibration.ReservoirState — Type
ReservoirState{T}

Masses (10^18 mol), isotopic compositions (per mil) and Sr ratios that are carried from one time step to the next (f90:279-294 and 529-545). Immutable: every step builds a new state, which keeps the time loop free of hidden mutation.

GeocarbPrecalibration.silicate_weathering_no_climate — Method
silicate_weathering_no_climate(i, src, bur, fE, fvolc, p, f) -> fwsi_no_climate

Silicate weathering at time t relative to the present without climatic effects: the silicate weathering required by mass balance (burial − carbonate weathering) divided by the non-climatic factors times Fwsi_0 (Berner 2004 eq. 5.2; "fB" in the BASIC code; f90:416).

GeocarbPrecalibration.source_fluxes — Method
source_fluxes(i, s, fE, fBB, p, f) -> NamedTuple

Weathering and degassing fluxes at time step i (10^18 mol/Myr; f90:363-378; see Berner 2006a pp. 5660-5661 for the Fwp, Fws and Fwg fluxes). Returned fields: Fwpy, Fwsy, Fwgy, Fwcy (young pyrite, CaSO4, organic C, carbonate C), Fwpa, Fwsa, Fwga, Fwca (old reservoirs), Fmp, Fms, Fmg, Fmc (degassing) and Fyop, Fyos, Fyog, Fyoc (degassing + old-reservoir weathering).

CO2 solver

GeocarbPrecalibration.solve_rco2 — Method
solve_rco2(t, rco2, fwsi_nc, gcm, RT, GEOG, p, o, k) -> (rco2, status, iterations)

Damped Newton solve for RCO2 (CO2 relative to 250 ppmv) at age t, starting from the previous step's value. Returns the new RCO2, a StepStatus (Converged, NotConverged or NaNEncountered) and the number of iterations.

The convergence test, damping, fallback shrinkage and failure rules are those of the Fortran (f90:431-521). In particular, convergence is judged on the relative step size (abs(RCO2/RCO2_old − 1) ≤ tol), and the iteration at which count == iteration_threshold is counted as a failure.

Climate

GeocarbPrecalibration.gcm_factor — Method
gcm_factor(t, p, o, k) -> GCM

Climate-sensitivity factor GCM ("capital gamma" in Berner 2004), with deltaT2X = GCM·ln 2:

  • in glacial intervals: GCM = GLAC·deltaT2X / ln 2;
  • otherwise, if o.dT2X_ramp and t ∈ (end, start] of o.dT2X_ramp_interval, the supplemental ramp: fac = (GLAC·(start − t) + (t − end)) / (start − end), GCM = fac·deltaT2X / ln 2 (run_geocarb_supp.f90:324-336);
  • otherwise GCM = deltaT2X / ln 2.

k are the ResolvedConstants (they carry ln 2, possibly rounded to single precision as in the Fortran).

source
GeocarbPrecalibration.in_glacial_interval — Method
in_glacial_interval(t, o::ModelOptions) -> Bool

true if age t (Myr ago) lies in one of the closed intervals o.glacial_intervals. With the defaults this is (260 ≤ t ≤ 330) || t ≤ 40 (f90:309). That follows Fielding et al. (2008); the original BASIC code used 270–340 Ma.

Vegetation

GeocarbPrecalibration.carbonate_fBB — Method
carbonate_fBB(t, rco2_prev, gcm, GEOG, p) -> fBB

Effect of climate and CO2 on carbonate weathering (Berner 2004 eqs. 2.6-2.7, 2.29), using RCO2 from the previous time step (f90:325, 336-343). Between 380 and 350 Ma the non-vascular and vascular expressions are blended linearly.

source
GeocarbPrecalibration.vegetation_fE — Method
vegetation_fE(t, p, o) -> fE

Effect of plants on the weathering rate at age t relative to the present (f90:319-359; supplemental variant run_geocarb_supp.f90:374-395):

age (Myr ago)fE
(380, 570]LIFE (non-vascular plants)
(350, 380]linear ramp LIFE → GYM
(start, 350]GYM (gymnosperms)
(end, start]linear ramp gym_factor·GYM → 1
[0, end]1 (angiosperms)

(start, end) = o.gym_angio_transition, default (130, 80). The Fortran checks the intervals one after another, with later checks overriding earlier ones; that order is kept. Unlike the Fortran supplemental code, GYM is never modified in place, so gym_factor = 0 is well defined (finding F-09).

Strontium and volcanic weathering

GeocarbPrecalibration.volcanic_weathering — Method
volcanic_weathering(i, src, bur, s, p, f, k) -> (Roc, Xvolc, fvolc)

Volcanic / non-volcanic silicate weathering, the "volc" in GEOCARBSULFvolc (Berner 2006b, 2008; f90:393-400):

  • Roc: 87Sr/86Sr of seawater as recorded in carbonates, Sr/10^4 + 0.7;
  • Rg: 87Sr/86Sr of non-volcanic silicates (Rnv in Berner 2006b);
  • Xvolc: fraction of Ca and Mg silicate weathering derived from volcanic rocks;
  • fvolc: volcanic weathering effect relative to the present.
source
GeocarbPrecalibration.volcanic_weathering_factor — Method
volcanic_weathering_factor(Xvolc, p) -> fvolc

fvolc = (VNV·Xvolc + 1 − Xvolc) / (VNV·Xvolc_0 + 1 − Xvolc_0), equal to 1 when Xvolc == Xvolc_0 (f90:400).
