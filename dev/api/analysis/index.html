Analysis and plotting API

Summaries of a precalibration result, and the plotting functions.

Summaries

GeocarbPrecalibration.DEFAULT_PROBS — Constant

Quantile levels used throughout the analysis scripts (analysis_and_plots.R:46).

source
GeocarbPrecalibration.parameter_quantiles — Method
parameter_quantiles(res; probs = DEFAULT_PROBS, n = nothing, rng = StableRNG(1))
    -> (names, probs, values)

Quantiles of every accepted constant parameter, plus the derived glacial sensitivity :deltaT2Xglac = deltaT2X·GLAC as the last row. values[i, j] is the probs[j] quantile of names[i]. With n, a subsample of n accepted samples is used, as the R analysis did to compare experiments of different sizes.

source
GeocarbPrecalibration.prior_posterior_table — Method
prior_posterior_table(table::PriorTable, res; probs = (0.05, 0.95)) -> NamedTuple

Prior mean and 5–95 % range against posterior median and 5–95 % range for every calibrated constant (som_parameters_table.csv, analysis_and_plots.R:485-537). The prior quantiles are those of the truncated priors.

source
GeocarbPrecalibration.row_quantiles — Method
row_quantiles(M; probs = DEFAULT_PROBS) -> Matrix{Float64}

Quantiles of every row of M, ignoring NaN (rows that are all NaN give NaN). ±Inf values are kept, as in R's quantile.

source
GeocarbPrecalibration.subsample_indices — Method
subsample_indices(n_available, n; rng = StableRNG(1)) -> Vector{Int}

n sample indices: without replacement if enough samples exist, otherwise with replacement (analysis_and_plots.R:84-88). n = nothing keeps all samples in order.

source
GeocarbPrecalibration.time_series_quantiles — Method
time_series_quantiles(res; probs = DEFAULT_PROBS) -> Array{Float64,3}

n_time × length(probs) × 12 quantiles of the accepted forcing series.

Correlations and survival

GeocarbPrecalibration.acf_quantiles — Method
acf_quantiles(res; lag_max = 10, probs = DEFAULT_PROBS) -> Array{Float64,3}

Quantiles across accepted samples of the autocorrelation function of each forcing series: (lag_max + 1) × length(probs) × 12 (analysis_and_plots.R:660-707).

source
GeocarbPrecalibration.correlation_screen — Method
correlation_screen(res, target::AbstractVector; method = :spearman) -> NamedTuple

Correlation of target (one value per accepted sample, for example the temperature at 100 Ma or ΔT2x) with every constant parameter, sorted by decreasing magnitude (analysis_and_plots.R:553-656). Returns (names, r).

source
GeocarbPrecalibration.survival_curve — Method
survival_curve(x) -> (x = sorted values, survival = 1 − ecdf)

Empirical survival function with ecdf = (1:n)/(n + 1) (analysis_supplemental_experiments.R:244-252).

Kernel density estimates

GeocarbPrecalibration.bw_nrd0 — Method
bw_nrd0(x) -> Float64

Silverman's rule-of-thumb bandwidth, identical to R's bw.nrd0: 0.9·min(sd, IQR/1.34)·n^(−1/5), with R's fallbacks for degenerate data.

source
GeocarbPrecalibration.gaussian_kde — Method
gaussian_kde(x; from = minimum(x) - 3bw, to = maximum(x) + 3bw, n = 512, bw = bw_nrd0(x))
    -> (x = grid, density = values)

Gaussian kernel density estimate on an evenly spaced grid of n points, evaluated exactly (R's density uses an FFT approximation of the same estimator).

Climate sensitivity

GeocarbPrecalibration.climate_sensitivity_summary — Method
climate_sensitivity_summary(res; probs = (0.05, 0.5, 0.95), exceed = (6.0, 7.0)) -> NamedTuple

The headline numbers of Wong et al. (2021): quantiles of ΔT2x, GLAC and the glacial sensitivity ΔT2x·GLAC, and Pr(ΔT2x ≥ x) for each x in exceed.

source
GeocarbPrecalibration.linear_interpolator — Method
linear_interpolator(x, y) -> function

Piecewise-linear interpolation through (x, y), returning NaN outside [minimum(x), maximum(x)] (R's approxfun with rule = 1). Used for the Park & Royer (2011) ΔT2x distribution.

source

Hindcast

GeocarbPrecalibration.hindcast — Method
hindcast(res::PrecalibrationResult; options = nothing, T0 = 15.0, include_geog = true,
         n = nothing, rng = StableRNG(1)) -> (co2, temp, idx)

Model CO2 (ppmv) and temperature (°C) of the accepted samples, as n_time × n matrices. Temperatures are temp + T0 plus, with include_geog = true, the sample's GEOG series, which is what the R analysis plots against proxies (analysis_and_plots.R:140).

With options = nothing, the model outputs saved during precalibration are reused (no model runs). Pass a ModelOptions to re-run every sample with different model options, for example the supplemental-experiment variants. n subsamples as in parameter_quantiles; idx are the samples used.

source
