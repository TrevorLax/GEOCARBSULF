Constant parameters

GeocarbPrecalibration.ConstantParams — Type
ConstantParams{T<:Real}

The 56 time-invariant parameters of GEOCARBSULFvolc. Field order matches the original Fortran Matrix_56; see CONSTANT_PARAMETER_NAMES. The meaning and units of each field are available with parameter_description and parameter_units.

Construct by name, never by position:

p = ConstantParams(Dict(:ACT => 0.09, :ACTcarb => 0.087, ...))   # all 56 names
p = ConstantParams(names, values)                                 # any order
p2 = update(p; deltaT2X = 4.0)

Missing or unknown names raise an ArgumentError.

Examples

julia> p = mean_constants(read_prior_table(datapath("GEOCARB_input_summaries_calib_all.csv")));

julia> p.deltaT2X
3.0

julia> update(p; deltaT2X = 4.0).deltaT2X
4.0

Time-varying forcings

GeocarbPrecalibration.TimeForcings — Type
TimeForcings{T<:Real}

The 12 time-varying forcings of GEOCARBSULFvolc on a common age grid (Myr ago, strictly decreasing, within [0, 570]). Fields: age and one vector per name in TIME_FORCING_NAMES.

Construct by name:

f = TimeForcings(age, Dict(:Sr => sr, :d13C => d13c, ...))   # all 12 names
f = TimeForcings(age; Sr = sr, d13C = d13c, ...)
f[:GEOG]                                                     # access by Symbol

Examples

julia> f = read_time_arrays(datapath("GEOCARB_input_arrays_NewDegassing.csv")).center;

julia> length(f.age), f.age[1], f.age[end]
(58, 570.0, 0.0)

julia> f[:GEOG] === f.GEOG
true

The vectors are mutable, so the samplers can overwrite them in place (sample_time_forcings!).

GeocarbPrecalibration.ModelOptions — Type
ModelOptions(; kwargs...)

Structural options of the GEOCARBSULFvolc model. The defaults reproduce fortran/src/run_geocarb.f90, including its single-precision literals. The supplemental experiments of run_geocarb_supp.f90 are expressed as options of the same model instead of a second copy of it.

keyworddefaultmeaning (Fortran reference)
dt10.0time step in Myr (Dt, f90:273); the age grid must have exactly this spacing
glacial_intervals[(260, 330), (-Inf, 40)]closed age intervals (Myr ago) in which GCM = GLAC*deltaT2X/ln 2 (f90:309)
gym_angio_transition(130, 80)start and end of the gymnosperm → angiosperm ramp in fE (supp age_gym_ang_beg/end)
gym_factor1.0multiplier on GYM during that ramp (supp gym_fac)
dT2X_rampfalseramp ΔT2x from deltaT2X to GLAC*deltaT2X over dT2X_ramp_interval (supp dT2X_fac ≥ 0)
dT2X_ramp_interval(130, 40)ages (Myr ago) at which the ramp factor is 1 and GLAC
iteration_threshold10iteration at which the CO2 solve is declared failed (parameterSetup.R:15)
convergence_tol0.01stop when abs(RCO2/RCO2_old - 1) <= tol (f90:435)
newton_damping0.9damping of each Newton step (f90:450)
newton_shrink0.2geometric shrinkage used when a step would make RCO2 non-positive (f90:452)
rco2_bounds(0.6, 200.0)RCO2 outside these bounds marks the step failed (150 and 50 000 ppmv; f90:524)
present_day_o2_percent(19.0, 23.0)present-day O2 (%) check (f90:561)
present_day_rco2(0.8, 1.2)present-day RCO2 check (f90:562)
corrected_newton_derivativefalseuse the exact derivative in the pre-380 Ma regime (finding F-01); false reproduces the Fortran
fortran_single_literalstrueround the decimal literals of the Fortran (0.01, 0.9, 0.2, 0.7, 0.6, 0.8, 1.2 and log(2.0)) to single precision, as gfortran does (finding F-05). This is what the published results were computed with, and it reproduces the compiled code to rounding error. false uses Float64 values instead. That is cleaner arithmetic, but it changes individual runs: in 1000 prior draws, 101 pass/fail decisions flip and CO2 moves by up to 14 % (see docs/src/porting_notes.md).

The supplemental experiment of the R code supp_experiment_parameters = c(beg, end, gym_fac, dT2X_fac) corresponds to ModelOptions(gym_angio_transition = (beg, end), gym_factor = gym_fac, dT2X_ramp = dT2X_fac >= 0). Note that the R default c(130, 80, 1, 1) enables the ΔT2x ramp (finding F-09); here the ramp is off unless asked for.

GeocarbPrecalibration.ResolvedConstants — Type
ResolvedConstants

Numerical constants actually used by the model (ln 2, solver tolerance and damping, Sr offset, RCO2 bounds, present-day checks), built from a ModelOptions by resolve_constants. When fortran_single_literals = true each value is rounded through Float32, as gfortran stores default-REAL literals in single precision (finding F-05). Internal; not part of the public API.

Truncated priors

GeocarbPrecalibration.TruncatedPrior — Type
TruncatedPrior

Prior of one constant parameter: an untruncated base distribution (Normal, LogNormal or Uniform) restricted to [lower, upper]. cdf_lower and cdf_upper are the base CDF values at the bounds.

Samples are drawn exactly as in lhs_sampling.R:39-65: a uniform u is rescaled into [cdf_lower, cdf_upper] and mapped through the base quantile function (see quantile_from_unit).

source
GeocarbPrecalibration.TruncatedPrior — Method
TruncatedPrior(s::PriorSpec)

Prior of a constant parameter from its CSV row. Gaussian: Normal(mean, two_sigma/2). Log-normal: LogNormal(log(mean), log(two_sigma/2)). Uniform: Uniform(lower, upper).
